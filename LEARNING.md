## 🛠️ Инструменты сборки (в процессе изучения)

### Gulp
**Зачем нужен:**
- Автоматизация рутинных задач
- Компиляция SCSS в CSS
- Минификация и конкатенация файлов
- Оптимизация изображений
- Живая перезагрузка браузера

**План изучения:**
1. Установка и настройка окружения
2. Базовые задачи (tasks)
3. Работа с плагинами
4. Создание workflow для проекта

### Webpack
**Зачем нужен:**
- Сборка модульных приложений
- Tree shaking и code splitting
- Работа с различными типами файлов
- Hot Module Replacement
- Оптимизация production-сборки

**План изучения:**
1. Базовая конфигурация
2. Loaders и plugins
3. Dev и production режимы
4. Оптимизация сборки

## 📝 Шаблонизаторы (в процессе изучения)

### Smarty (PHP)
**Основные концепции для изучения:**
- Синтаксис переменных `{$variable}`
- Циклы и условия
- Модификаторы
- Подключение файлов
- Кеширование

### Blade (Laravel)
**Основные концепции для изучения:**
- Директивы `@if`, `@foreach`
- Наследование шаблонов `@extends`, `@section`
- Компоненты
- Slots
- Включения `@include`

## 📧 Email-верстка (в процессе изучения)

**Особенности:**
- Табличная верстка
- Inline-стили
- Ограничения почтовых клиентов
- Адаптивность
- Тестирование в разных клиентах

**Инструменты:**
- MJML - фреймворк для email
- Litmus - тестирование
- Email on Acid

**План:**
1. Изучить основы табличной верстки
2. Понять ограничения разных почтовых клиентов
3. Научиться делать адаптивные письма
4. Создать 5-10 различных email-шаблонов

## 🎯 ЧТО ДЕЛАТЬ ДАЛЬШЕ (пошагово)

### ШАГ 1: Создайте репозиторий (5 минут)

1. Перейдите на [github.com](https://github.com)
2. Нажмите "New repository"
3. Назовите репозиторий **точно так же, как ваш username**
4. Сделайте его **публичным**
5. Не инициализируйте с README (он уже есть)

### ШАГ 2: Загрузите файлы (5 минут)

```bash
# В текущей директории (d:\Programming\Project\git)
git init
git add .
git commit -m "Initial commit: Professional GitHub Profile"
git branch -M main
git remote add origin https://github.com/EvgenYanukovich/EvgenYanukovich.git
git push -u origin main
```

### ШАГ 3: Замените плейсхолдеры (10 минут)

Найдите и замените во ВСЕХ файлах:

| Найти | Заменить на |
|-------|-------------|
| `YOUR_USERNAME` | EvgenYanukovich |
| `your_username` | evyanukovich |
| `your.email@example.com` | evgen.yanukovich@gmail.com |
| `+7 (XXX) XXX-XX-XX` | +375 (29) 598-03-22 |

**Быстрая замена в VS Code:**
- `Ctrl + Shift + H` (Replace in Files)
- Введите что искать → что заменить
- "Replace All"

### ШАГ 4: Активируйте GitHub Actions (2 минуты)

1. Откройте ваш репозиторий на GitHub
2. Перейдите в "Actions"
3. Если появится запрос — нажмите "I understand, enable them"
4. Запустите "Generate Snake" вручную (Run workflow)

### ШАГ 5: Создайте 2-3 проекта (1-2 дня)

**Минимальное портфолио:**

1. **Landing Page** (обязательно)
   - Адаптивный лендинг по макету из Figma
   - Используйте SCSS, БЭМ
   - Разместите на GitHub Pages

2. **Многостраничный сайт** (обязательно)
   - 3-5 страниц
   - Навигация, формы
   - Bootstrap или свой UI

3. **WordPress тема** (опционально, но желательно)
   - Простая базовая тема
   - Кастомные поля
   - Покажет знание CMS

**Где взять макеты:**
- [Figma Community](https://www.figma.com/community)
- [Frontend Mentor](https://www.frontendmentor.io)
- [Behance](https://www.behance.net)

## 🆘 НУЖНА ПОМОЩЬ?

### Если что-то не работает:

1. **GitHub Actions не запускаются:**
   - Проверьте, что репозиторий публичный
   - Включите Actions в настройках
   - Запустите workflow вручную

2. **Профиль не отображается:**
   - Имя репозитория = ваш username
   - README.md в корне репозитория
   - Репозиторий публичный

3. **Не знаете, что писать в проектах:**
   - Используйте готовые макеты
   - Начните с простого лендинга
   - Главное — качество, не количество
